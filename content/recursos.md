## Cómo contribuir

Este wiki es un espacio vivo. Para agregar notas:

1. Crea un archivo `.md` en la carpeta `content/`
2. Agrega frontmatter con `title:`
3. Haz commit y push a la rama `v5`

El sitio se actualizará automáticamente via GitHub Actions.
